# Bem Lembrado 🎙️💊
> **Aplicativo de Organização e Lembretes por Voz com Fechamento de Ciclo para Medicação**  
> Projeto desenvolvido para a disciplina de *Inovações para Engenharia (ESMA002-23)*.

---

## 🌟 Sobre o Projeto
O **Bem Lembrado** resolve a sobrecarga diária e o esquecimento de tarefas e medicamentos.
Em vez de passar 30 a 45 segundos desbloqueando o celular, digitando título, data e categoria, o usuário dá **1 toque** e fala naturalmente (ex: *"Remédio de pressão às 20h"* ou *"Reunião amanhã às 14h"*).

### Principais Inovações
1. **Fricção Mínima:** 1 toque, falar e pronto. Sem interfaces complicadas.
2. **Classificação e Extração Inteligente:** Detecta automaticamente se é medicação, compromisso ou tarefa, agendando o horário.
3. **Fechamento de Ciclo (Diferencial para Medicação):** O app não só avisa no horário do remédio, como dispara uma checagem 15 minutos depois: *"Você tomou o remédio?"*, com confirmação em botão de um toque.
4. **Visão Conforto (Acessibilidade Inclusiva):** Alternador de alto contraste e fontes ampliadas sem jargões estigmatizantes.

## 🚀 Como Executar

### 1. Iniciar o servidor
Na pasta do projeto, execute no terminal:
```bash
python backend/server.py
```

### 2. Acessar
* **No Computador:** `http://localhost:8000`
* **No Celular (mesmo Wi-Fi):** `http://192.168.68.107:8000`
